# AquaGuardian AI — GPIW Competition Package v3.0

AquaGuardian is a **TRL 3 closed-loop engineering proof of concept for water infrastructure**.

`Sense → Analyze → Simulate → Stress Test → Optimize → Validate → Execute`

Instead of only detecting an anomaly, AquaGuardian evaluates candidate responses in a deterministic digital twin, rejects unsafe plans under stress profiles and produces an auditable decision trail before action.

## Submission position

- **Track/readiness:** Discovery-stage, TRL 3.
- **Beachhead customer:** commercial farms and managed irrigation districts in water-stressed regions.
- **Current evidence:** reproducible software simulation, tests and comparative baselines.
- **Not claimed:** field performance, autonomous production control or certified critical-infrastructure security.

## What is computed

- risk scores from sensor frames;
- candidate action simulation;
- stress-profile validation;
- action selection, confidence and reliability;
- comparison with reactive and detection-only baselines;
- UI metrics generated by the backend;
- downloadable JSON evidence;
- live edge-hardware, network, and MEC-layer numbers from a bundled
  independent simulator (see "Hardware layer" below).

Scenario narration and network artwork are explanatory. Numerical comparison cards and final validation metrics are generated by the backend. Results are deterministic PoC simulations, **not field-trial claims**.

## Hardware layer: `hexa_tpu_rt_sim`

`/hexa_tpu_rt_sim` is a separate, independently developed architecture
simulator merged into this repository. It models the edge-hardware
claims underneath AquaGuardian's "sense locally, decide before the
network round trip" story:

- **Reflex kernel** (`reflex/reflex_kernel.py`) — a domain-neutral,
  bounded-latency decide-and-act path with a hard sub-1ms deadline,
  reused unmodified between this project's water domain
  (`reflex/domains/water.py`, a water-hammer/pipe-burst trigger) and
  an aviation Detect-and-Avoid domain in the same package.
- **Network layer** (`network/urllc_link.py`) — a statistical model of
  the edge → MEC hop as a 5G NR URLLC link, calibrated to a 10ms SLA.
- **MEC cognitive layer** (`mec/domains/water_cognitive_engine.py`) —
  a bio-inspired stack (Bat Forecaster for remaining-useful-life
  projection, Squid Controller for weighted action selection, a
  Hermit-Crab-style hard veto against water-hammer-risk actions)
  reused, class-for-class, from the platform's aviation domain.

`app/hardware_bridge.py` calls this simulator directly and
`GET /api/hardware/reflex` returns freshly computed results each time
it's called — the "beyond water" section of the console displays
these numbers live, not as copied constants. `hexa_tpu_rt_sim` has its
own README, tests, and benchmarks; see that directory to run it
standalone.

## Run with Docker

```bash
docker compose up --build
```

Open:

- Console: `http://localhost:8000`
- Health: `http://localhost:8000/api/health`

Stop:

```bash
docker compose down
```

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Tests and evidence

```bash
pip install -r requirements-dev.txt
pytest -q
python scripts/run_demo.py
python scripts/run_stress_matrix.py
python scripts/run_comparison.py
```

## Security configuration

The PoC defaults CORS to local origins. To set an explicit allow-list:

```bash
AQUAGUARDIAN_CORS_ORIGINS=https://demo.example.com,https://review.example.com
```

The current package has no production authentication or actuator connection. See the security roadmap before any field deployment.

## GPIW focus

Water scenarios include pipeline leakage, pump degradation, contamination, drought stress and wildfire risk. The Green Box aviation scenario is retained only as a heritage demonstration of architecture portability and is excluded from water-impact aggregate claims.
