# GPIW Submission Checklist

**Deadline: September 30, 2026** (application window opened June 4, 2026).
Track A (TRL 1–3), Category: Digitalisation, Automation and Smart Water
Management — see `docs/GPIW_TRACK_AND_CATEGORY.md` for the rationale.

## Portal requirements (from the official 2026 Applicant Guidelines)

- [x] Track and category selected and justified — `docs/GPIW_TRACK_AND_CATEGORY.md`
- [x] Draft answers for Innovation Overview, Technical Questions, Impact &
      Market, Team & Org Maturity — `docs/GPIW_APPLICATION_DRAFT.md`
- [x] Pitch deck / technical summary, ≤20 slides, PDF or PPT, ≤20MB — see
      `outputs/AquaGuardian-GPIW-Pitch-Deck.pptx`
- [ ] Video presentation, 1–2 min, MP4/MOV/AVI, ≤50MB — script drafted in
      `docs/GPIW_VIDEO_SCRIPT.md`, **not yet recorded**
- [ ] Supporting evidence upload (optional, PDF/ZIP, ≤30MB) — this repository
      (or a trimmed export of it) is a natural candidate
- [x] Self-assessment against the 8 official criteria —
      `docs/GPIW_SELF_ASSESSMENT.md`
- [ ] Confirm every form field and character limit on the live portal — the
      Guidelines describe section structure but not exact field limits

## Technical package

- [x] One integrated FastAPI application and web console.
- [x] Docker and local run instructions.
- [x] Engine, API and comparative tests.
- [x] Reproducible JSON evidence.
- [x] Simulation limitations clearly disclosed.
- [x] Traditional, detection-only and closed-loop comparison.

## Readiness and safety

- [x] Current readiness stated as TRL 3.
- [x] Path to TRL 4–6 documented.
- [x] Threat model and production security roadmap.
- [x] Local CORS allow-list by default.
- [x] No production actuator-control claim.

## Business and impact

- [x] Beachhead customer defined.
- [x] Commercial model and pricing hypotheses documented.
- [x] Competitive categories compared objectively.
- [x] Deployment-impact calculation method documented.
- [ ] Validate assumptions through customer interviews.
- [ ] Obtain a letter of interest from a pilot partner.

## Ownership and team

- [x] IP and provenance statement.
- [x] Open-source dependency boundary.
- [x] Team credibility and capability gaps documented.
- [ ] Verify all final visuals, datasets and dependencies against current competition terms.

## Final presentation assets

- [ ] Record the demonstration video.
- [ ] Add the final public repository URL.
- [ ] Add the live demo URL if available.
- [ ] Add a signed pilot or design-partner letter if available.
- [ ] Confirm every form field and current deadline on the official GPIW portal.
